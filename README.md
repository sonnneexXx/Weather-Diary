# 🌤️ Weather Diary - Дневник погоды

**Глущенко Вадим** 

## 📝 Описание программы

Weather Diary - это консольное приложение для ведения дневника погоды с возможностью визуализации температурных изменений. Приложение позволяет записывать ежедневные погодные данные, анализировать их и строить графики температуры.

### Основные возможности

- ✅ **Добавление записей** о погоде (дата, температура, описание, осадки)
- ✅ **Просмотр всех записей** со статистикой
- ✅ **Фильтрация** по датам и температуре
- ✅ **Построение графиков** температуры с помощью matplotlib
- ✅ **Расширенная статистика** и анализ погодных данных
- ✅ **Советы по погоде** на основе введённых данных
- ✅ **Редактирование** существующих записей
- ✅ **Сохранение и загрузка** данных в JSON

### Принципы ООП

- **Инкапсуляция**: данные скрыты внутри классов, доступ через методы
- **Наследование**: абстрактный класс `WeatherType` и конкретные типы погоды
- **Полиморфизм**: разные реализации методов `get_emoji()` и `get_advice()`
